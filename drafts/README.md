# Solar House VK — материалы на согласовании

**Актуальная редакционная стратегия (с 19 ноября):** четыре статьи с
иллюстрациями в неделю, видео владелец снимает и публикует сам. Список
кандидатов на 20–26 ноября — `2026-11-20_26-articles-only.json`;
первоначальный пакет с клипами сохранён только как архив. Автоматических
историй в текущем плане нет. Ни один из новых постов пока не утверждён.

Файлы этой папки **не являются очередью публикации**. Действующий облачный
издатель читает исключительно `queue/*.json`. Переносить утверждённый материал
в `queue/` можно только после проверки подходящего способа публикации.

Утверждённые видео перемещаются в `media/` и ставятся в отдельную очередь
`videos-queue/`. Видео предварительно загружается с компьютера через Chrome;
облачная публикация работает только при отдельном `VK_VIDEO_ENABLED=true` и
подтверждённом ID видеозаписи сообщества. Дополнительный пользовательский
токен в GitHub не нужен. Сам файл в `drafts/` публикацию не запускает.

Для историй есть отдельная очередь `stories-queue/` и облачный издатель,
который запускается только при `VK_STORIES_ENABLED=true`. Наличие файлов
в `drafts/` само по себе **ничего не публикует**.
